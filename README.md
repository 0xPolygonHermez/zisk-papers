## Build

This is a [Typst](https://typst.app/) whitepaper. 

To refresh the committed PDF, use the build script:
```sh
./scripts/build.sh
```

To watch for changes and recompile automatically while drafting:
```sh
typst watch src/main.typ src/main.pdf
```
